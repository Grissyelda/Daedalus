# Bring in a model

Use your own models, from Blender or anywhere else. See [Models](things/models).

- [ ] **Bring one in.** Drag a .glb, .gltf or .obj file from your desktop onto the editor, or use **Bring in** in the Kits tab. {check: model.imported} {show: kits/importmodel}
- [ ] **Place another copy.** In the **Kits** tab, drag the model's tile into the view. {check: model.placed} {show: tab:Kits}
- [ ] **Fix its size.** Select it and change **Made in** on the Model card, if it came out too big or too small. {check: model.size}
- [ ] **Change it at the source.** Save the file again in the program you made it in, and watch it update. {check: model.updated}
