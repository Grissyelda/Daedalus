# Model card

For things showing a model file.

- **Size** shows how big the model is, in meters. Hover it for game units.
- **Made in** sets the size: what the model was made in. glTF files are made in meters.
- **Turn** turns the model itself a quarter left or right, for every copy.
- **From** is the file it came from. Save that file again and the model updates by itself; **Update now** reads it straight away, and **Show the file** opens its folder.
- Notes in yellow are things the import couldn't do, such as a see-through material drawn with cut-out edges. They're in Problems too.

See [Models](things/models).
