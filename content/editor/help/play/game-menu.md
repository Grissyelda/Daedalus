# The game menu

Games made with Daedalus, and games like the original DOOM 3 whose menus Daedalus can't use, get Daedalus' own game menu. It opens by itself when the game starts without a level, and **Esc** opens it while playing (the game pauses behind it).

- **Carry on** goes back to the game.
- **New game** starts the game's first level (DOOM 3 and Resurrection of Evil).
- **Choose a level** lists every level the game has.
- **Quick save** and **Quick load**.
- **Settings**:
  - **Display**: full screen, window size, field of view, vertical sync, frame rate, brightness, and the frame-rate counter.
  - **Controls**: mouse speed and inverted look, always run, crouch and run that toggle, gamepad and its dead zone, and the keys for each action: click one, then press the key you want.
  - **Sound**: the volume.

The DOOM 3 BFG Edition uses its own menus.
